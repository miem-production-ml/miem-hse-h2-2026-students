# All Cups 3521: baseline регрессии

Пакет соответствует [задаче All Cups 3521](https://cups.online/tasks/3521) и используется на занятии 4 как старт для домашней работы.

Ноутбук повторно выполнен с начала до конца в новом kernel Python 3.11.16 19 октября 2026 года. CSV прошёл локальную проверку формата и получил числовые public/private оценки через проверку организатора All Cups. Актуальные даты приёма и доступность задания смотрите на странице соревнования.

## Контракт

- `data/train.csv`: 100 000 строк, 24 столбца признаков и `price`.
- `data/test.csv`: 100 000 строк без target; `id` служит идентификатором строки.
- `data/sample_submission.csv`: точный регистр и порядок столбцов `id,price`.
- MAE ниже — лучше. Платформа показывает `score = 1 / (1 + MAE)`, выше — лучше.
- Train/test разделены по времени; public/private test — случайно в пропорции 30/70.

## Практика: 35 минут

| Минуты | Действие |
|---|---|
| 0–4 | Прочитать данные и проверить контракт |
| 4–8 | Отсортировать по `date,id`, последние 20% строк оставить для validation |
| 8–13 | Сравнить Dummy по медиане и Ridge с `alpha=1` |
| 13–18 | Объяснить MAE; посмотреть остальные регрессионные метрики |
| 18–22 | Обучить Ridge на полном train и собрать CSV |
| 22–25 | Проверить формат и сформулировать одну гипотезу |
| 25–32 | Сохранить исходный CSV; изменить только alpha 1 → 10 в локальном сравнении |
| 32–35 | Сравнить тот же holdout и объяснить наблюдение |

Preprocessing обучается только на обучающей части holdout. Граница по 80% строк может пройти внутри одного месяца: это простой хронологический holdout, а не гарантия разделения целых месяцев.

В последние 10 минут практики самостоятельно изменить только `alpha` с 1 на 10 и сравнить тот же holdout. Полиномиальные признаки, Lasso и робастные потери — дополнительные эксперименты.

## Запуск до занятия

Используйте Python 3.11+ и отдельное окружение. Из каталога `competition`:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab baseline_regression.ipynb
```

В Windows активация: `.venv\Scripts\activate`. Выполните Restart Kernel → Run All. Пути данных относительные; файл `baseline_submission.csv` появится рядом с notebook. Установка зависимостей выполняется заранее и не входит в 35 минут практики.

Проверка CSV встроена в последнюю кодовую ячейку: она проверяет столбцы, число строк, порядок ID и допустимость прогнозов. Выполните её без ошибок перед отправкой.

Если настройка среды задерживается более двух минут, используйте сохранённый `baseline_submission.csv` и разберите шаги ноутбука. Установка пакетов не входит в 35 минут практики.

Дополнительный кейс AI4I с классификацией предоставляется отдельно для самостоятельного изучения. Его CSV не подходит для основного задания All Cups.
